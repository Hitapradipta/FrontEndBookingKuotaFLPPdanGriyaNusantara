# 🏠 Frontend Booking Kuota FLPP & Griya Nusantara

## 📝 About The Project
This repository contains the frontend application for the **Booking Kuota FLPP (Fasilitas Likuiditas Pembiayaan Perumahan)** and **Griya Nusantara** platform. It provides a user-friendly, responsive interface for users and administrators to manage housing subsidy quotas, browse property catalogs, and handle booking workflows seamlessly.

## ✨ Features
- **Quota Booking Management**: Streamlined interface for booking and managing FLPP housing quotas.
- **Property Catalog**: Browse and book properties available under Griya Nusantara.
- **Responsive UI**: Fully optimized for desktop, tablet, and mobile devices.
- **Type Safety**: Built with TypeScript for a robust, maintainable, and scalable codebase.
- **Containerized Deployment**: Out-of-the-box support for Docker and Docker Compose.
- **Modern Tooling**: Powered by Vue 3 (Composition API) and Vite for lightning-fast development and builds.

## 🛠️ Tech Stack
- **Framework**: [Vue.js 3](https://vuejs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: SCSS / CSS
- **Package Manager**: [pnpm](https://pnpm.io/)
- **Containerization**: Docker & Docker Compose
- **Code Quality**: ESLint, Stylelint, SonarQube integration

## 📂 Project Structure
The project follows a modern Vue 3 + Vite + TypeScript architecture:
- `src/`: Main application source code (components, views, router, stores, assets).
- `public/`: Static assets served directly without build processing.
- `docker-compose.yml`: Configuration for running containerized services.
- `vite.config.ts`: Vite build tool and plugin configurations.
- `.env.example`: Template for required environment variables.
